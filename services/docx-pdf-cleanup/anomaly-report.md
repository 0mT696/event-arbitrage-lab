- **对应原稿**：`sample-before.md`
- **对应清理稿**：`sample-after.docx` / `sample-after.pdf` / `sample-after.md`
- **锚点口径**：`S1`–`S6` 为原稿人工页签；`¶n` 为该页签内可叙述单元的顺序锚点。因原稿页脚互相矛盾，不以旧页脚数字定位。
- **严重度**：高＝事实、数字、隐私或表格含义可能出错；中＝结构、重复或分页影响验收；低＝排版、字符宽度或文风。
- **处理纪律**：只修正可确定的格式问题；数字冲突、无来源主张和缺件均列入文末「异常与待核清单」，不擅自补写。本样例全部为虚构数据；真实业务应先脱敏。
- **规模**：40 条异常行，归为 11 类：标题层级、空白/分隔、字符宽度/语言、表格、页码/交叉引用、重复内容、来源/引文、数字/口径冲突、事实边界、PII、日期语义。

## 复核重点

1. **逐行回到原稿锚点**：确认每条摘录可在 `sample-before.md` 找到，且清理稿状态真实。
2. **数字盲核**：12,480 = 5,260 + 4,180 + 3,040；42 = 18 + 14 + 10；222 = 96 + 72 + 54；8,640 = 3,200 + 4,240 + 1,200。勾稽成立不等于原始凭证已核验。
3. **冲突必须仍在**：预算96,000 vs 95,000、志愿者每班3小时 vs 3.5小时、42%无口径、宣传实际支付未提供，均不得被「修好」。
4. **页码说明**：清理稿 DOCX/PDF 的页脚为新排版页码，原稿 `S1`–`S6` 仅用于追溯，不能宣称11 类异常已在新文件中保持一一对应页位。
5. **样例非销售证据**：本表只证明一个固定样例的处理与记录能力，不证明真实客户文件已完成，也不证明有人曾购买此服务。
