## 3. 六条不可协商门禁的代码落点（不变）

1. 非预测性交易才叫套利 → `rules.validate_market_rules()` / `VenuePairMapping.usable()`
2. mid/last 价不可作可执行成本 → `vwap.walk_book()` 只走真实盘口深度
3. 一腿无法成交则机会无效 → `strategies.two_leg_arbitrage()` min 深度撮合 + 重报价
4. 部分成交显式处理 → N3 撮合量收缩 + N4 状态机/残仓/unwind
5. net edge 含费用/滑点/结算/资金占用假设 → `Opportunity` 全字段拆分 + `assumptions`
6. 初版无实盘下单路径 → 全部模块零下单/签名/凭证；I/O 仅 adapter 只读
